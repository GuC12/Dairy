# ATMOS_ // Материалы для сдачи на Genesis Hackathon (ArtTech)

Этот документ содержит готовые тексты для всех полей формы сдачи (Раздел 09 кейса **«Make the Invisible Visible_»**).

---

## 1. Описание до 1 страницы (Идея, аудитория, правила визуальной системы)

**Идея продукта:**
Фотографии в телефоне хранят то, как день выглядел, но не то, как он ощущался. **ATMOS_** — это интерактивный личный дневник-галерея, который превращает один день (свободный текст или голосовой рассказ, фотографии и песню) в живое мультисенсорное воспоминание формата **4:5** и сохраняет все артефакты в именную **Папку дня**. Открыв запись спустя год (или нажав «Капсула времени»), человек снова видит свет, мазки, погоду и слышит ритм и голос того самого дня.

**Аудитория:**
Люди, которые хотят сохранять личную историю и эмоциональную память о важных днях без шаблонного ведения соцсетей — в приватном, эстетичном цифровом арт-дневнике.

**Правила единой визуальной системы (Постоянное vs Переменное):**
Дневник строится как единая серия коллекционных страниц, где каждая запись подчиняется общим законам:
* **Постоянные элементы (Цельность ленты):**
  1. Фиксированный вертикальный формат постера **4:5** с внешней рамкой-паспарту.
  2. Единая типографическая сетка: сверху — моноширинный каталожный индекс `DAY // XX`, 4 Pantone-чипа доминирующих цветов дня, дата и погода; снизу — поэтичное название папки (3–7 слов) на антикве *Cormorant Garamond*, строка музыкального пульса и рукописная подпись (*Caveat*).
  3. Центральное окно кадра, внутри которого живут фотографии и процедурные художественные слои.
* **Переменные элементы (Как Текст + Фото + Музыка меняют форму):**
  1. **Текст и погода** определяют координаты *Valence* (холод ↔ тепло), время суток, сезон, запускают движок погодных частиц на холсте (осенний листопад, капли дождя и молнии, утренний туман, снегопад), генерируют название папки (3–7 слов) и настраивают тембр/темп синтеза речи для озвучки.
  2. **Фотографии** проходят через алгоритмическое квантование на HTML5 Canvas: извлекаются 4 доминирующих HEX-цвета, средняя яркость и контраст, которые окрашивают паспарту, мазки кисти и динамическую ауру всего сайта.
  3. **Музыка** анализируется через Web Audio API (`decodeAudioData` и `AnalyserNode` в 60 FPS) или подтягивается в виде официального 30-секундного превью трека с виниловым эмбиент-слоем. Темп (BPM), энергия и лад (мажор/минор) управляют скоростью кроссфейда кадров, шириной «воздуха» вокруг фото и пульсацией геометрии.

## 2. Художественные приёмы и референсы

Система автоматически выбирает один из 4 художественных режимов по координатам `Valence × Energy`:

1. **Импрессионизм / Клод Моне (`impressionism`)**
   * *Когда включается:* тёплые, светлые, ностальгические дни, мажорный лад, мягкий свет на снимках.
   * *Приёмы:* многослойные полупрозрачные эллиптические мазки кисти из палитры фото, золотистые пылинки света (боке), диффузное свечение и плавный кроссфейд кадров.
2. **Конструктивизм и Абстракционизм / Василий Кандинский (`constructivism`)**
   * *Когда включается:* высокий темп (>115 BPM), высокая энергия, ночная работа, дедлайны, электронная музыка.
   * *Приёмы:* глубокая сапфирово-кобальтовая палитра, жёсткая сетка пересекающихся осей, импульсные концентрические круги и диагональные векторы, реагирующие на бас, резкий ритмичный монтаж кадров.
3. **Японский минимализм / Ваби-саби (`wabi-sabi`)**
   * *Когда включается:* медленный темп (≤82 BPM), минорная тональность, туман, тишина, созерцание.
   * *Приёмы:* увеличенное количество «воздуха» (широкое паспарту), нефритово-селадоновые приглушённые тона, слои плывущего тумана, асимметричная линия туши и красная квадратная печать *ханко* с номером дня.
4. **Аналоговая киноплёнка 35mm / Коллаж (`film-35mm`)**
   * *Когда включается:* живые городские прогулки, транспорт, смешанные эмоции, инди/джаз/поп среднего темпа.
   * *Приёмы:* бегущая в такт BPM плёночная перфорация по краям кадра, тёплые боковые засветки (*light leaks*), органичное плёночное зерно и живое покачивание кадра.

## 3. Использованные инструменты и технологии

* **Frontend & Архитектура:** React 19, TypeScript, Vite.
* **Компьютерная графика и анализ изображений:** HTML5 Canvas 2D API (квантование пикселей для извлечения палитры, яркости и контраста; процедурные кисти Моне, геометрия Кандинского, система погодных частиц, тактильный отклик на курсор).
* **Аудиоанализ и синтез звука:** Web Audio API (`AnalyserNode` 60 FPS, расчёт RMS-энергии и пикового BPM, процедурный аккордовый синтезатор + генератор винилового треска), iTunes Search API (поиск и воспроизведение официальных 30-секундных фрагментов песен без нарушения авторских прав).
* **Речь и озвучка:** Web Speech API (`SpeechSynthesis` с адаптивным подбором `rate`/`pitch` и авто-приглушением музыки *ducking*; `SpeechRecognition` для голосовой диктовки записи).
* **Экспорт и хранение:** `IndexedDB` (локальное хранение папок дней), `HTMLCanvasElement.captureStream(30)` + `MediaRecorder API` (запись 7-секундных видеоклипов `.webm` со звуком прямо в браузере), экспорт постеров в `.png` и обмен папками `.atmos.json`.
* **Гео-контекст:** Open-Meteo API & Nominatim API (авто-определение погоды и города с согласия пользователя).

## 4. Сценарий видеодемонстрации (до 3 минут)

* **0:00 – 0:30 // Архив и Проверка лентой:**
  Показать главный экран архива: 5 разных по атмосфере дней в единой сетке 4:5, Хроматический спектр дневника, 2D-компас настроений. Навести курсор на 2–3 карточки (выезжают виниловые пластинки, перекрашивается фоновая аура сайта), переключить вид «Постеры» ↔ «Развороты» и тему «Chromatic Prism» ↔ «Genesis Paper».
* **0:30 – 1:30 // Создание любимого дня (Live Studio):**
  Перейти во вкладку **«Новый день»**. Нажать **«🎙 Надиктовать голосом»** (или ввести текст любимого дня) и **«📍 Авто-погода и город»**. Перетащить 2–3 реальные фотографии дня (показать, как мгновенно извлеклись 4 цвета). В поиске трека найти песню с 30-сек превью. Показать, как справа в **Live Preview** страница 4:5 перестроилась на лету. Нажать «Сохранить».
* **1:30 – 2:20 // Папка дня, Озвучка и Объяснимая логика:**
  В открывшейся папке дня включить музыку, провести мышкой по картине 4:5 (показать тактильный след и погодные частицы), нажать **«Озвучить»** (музыка плавно приглушается, звучит подобранный голос). Прокрутить к блоку **«Объяснимая логика»** и 6 шкалам **«Математика визуальной системы»**. Скачать открытку **PNG** или **Видео WebM (7с)**.
* **2:20 – 2:50 // Капсула времени и Лаборатория системы:**
  Открыть вкладку **«Визуальная система»**, покликать интерактивный стенд (4 стиля и 4 погоды на одном кадре), затем вернуться в Архив и нажать **«Фильм»** или **«Капсула»** для полноэкранного финала.
