# ATMOS // Make the Invisible Visible_

Личный дневник ощущений для кейса **Genesis Hackathon // ArtTech**.
Превращает один день — **текст, фотографии и песню** — в живое воспоминание в формате **4:5**, подчиняющееся единой визуальной системе, и сохраняет всё в отдельную **Папку дня**.

## Быстрый запуск

```bash
npm install
npm run dev
```

Для продакшн-сборки:
```bash
npm run build
```

## Что реализовано

1. **Архив дней (Проверка лентой):**
   - 4 предзагруженных демонстрационных дня с разным настроением и художественными приёмами.
   - Все записи отображаются в единой модульной сетке 4:5 — лента выглядит как страницы одного дневника.
   - Поиск по папкам, тексту и песням, фильтрация по художественным направлениям.

2. **Создание нового дня:**
   - Свободный текст + опциональные дата, погода, локация и подпись.
   - Загрузка 1–6 фотографий с автоматическим извлечением 4 доминирующих цветов, яркости и контраста через HTML5 Canvas.
   - Добавление музыки:
     - **Аудиофайл** (MP3/WAV/OGG) — реальный анализ RMS-энергии и BPM через Web Audio API + живая 60 FPS визуализация спектра.
     - **Ссылка на сервис** (Spotify / YouTube и др.) — сохранение ссылки + встроенный процедурный эмбиент-синтезатор под выбранный BPM и тональность.

3. **Папка дня и Объяснимая логика:**
   - Автоматическое придумывание короткого названия папки (3–7 слов).
   - Хранение в IndexedDB: текст, фото, музыка, воспоминание и профиль озвучки.
   - Озвучка текста через Web Speech API с подбором скорости и высоты голоса под атмосферу дня.
   - Экспорт готовой страницы-открытки в PNG.
   - Прозрачный блок **«Почему день выглядит так»** с разбором влияния текста, фото и музыки.

4. **Опциональное усиление через Gemini API:**
   - Базово всё работает **полностью автономно в браузере** без ключей.
   - В настройках (`Local Engine / Gemini ON`) можно указать ключ Gemini API для модели `gemini-2.5-flash` для расширенного смыслового анализа.

## Единая визуальная система

- **Постоянные элементы:** формат 4:5, внешняя рамка-паспарту, моноширинный индекс `DAY // XX`, зона даты и погоды, антиквенный заголовок папки, музыкальная строка и рукописная подпись.
- **Переменные элементы:** палитра из фото, плотность «воздуха», плёночное зерно, ритм смены кадров и 4 художественных приёма:
  1. **Импрессионизм (Клод Моне)** — для тёплых, спокойных и ностальгических дней.
  2. **Конструктивизм (Василий Кандинский)** — для напряжённых, ритмичных дней и дедлайнов.
  3. **Японский минимализм (Ваби-саби)** — для тихих, медленных и минорных дней.
  4. **Аналоговая плёнка 35mm** — для живых городских прогулок и хроник.
