# YourDiary // ArtTech: Make the Invisible Visible

Личный дневник ощущений для кейса **ArtTech: Make the Invisible Visible** (19–22 ноября 2026).  
Превращает один день — **текст, фотографии и музыку** — в живое воспоминание формата **4:5**, подчиняющееся единой визуальной системе, и сохраняет всё в отдельную **Папку дня** с облачной синхронизацией.

---

## Быстрый запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173/`.

Для проверки типов, сборки и линтера:
```bash
npm run build
npm run lint
```

### Переменные окружения (опционально)
Скопируйте `.env.example` в `.env.local` при использовании собственных ключей:
- `VITE_CLERK_PUBLISHABLE_KEY` — ключ Clerk для личных аккаунтов (почта, логин, 6-значный код, сброс пароля).
- `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` — облачная синхронизация профилей и папок дней (таблицы создаются скриптом [`SUPABASE_SETUP.sql`](./SUPABASE_SETUP.sql)).
- `VITE_GEMINI_API_KEY` — опциональный ключ Gemini 2.5 Flash для расширенного смыслового анализа. Без него всё работает автономно в браузере + через живой поиск музыки.

## Что реализовано

1. **Личные аккаунты и облачная синхронизация:**
   - Регистрация с **именем пользователя** и **электронной почтой** + подтверждение 6-значным кодом через **Clerk**.
   - Вход по логину или почте, поддержка Client Trust / 2FA по коду из письма и восстановление пароля через email-код.
   - Гибридное хранение: мгновенный локальный отклик в **IndexedDB** + автоматическая синхронизация в облако **Supabase** (`profiles` и `diary_entries`).

2. **Архив дней (Проверка лентой):**
   - Все записи отображаются в единой модульной сетке **4:5** — лента выглядит как страницы одного дневника.
   - Переключение видов: *Постеры* / *Развороты*, 2D-компас настроений, хроматический спектр дневника, режимы *Фильм* и *Капсула времени*, поиск и фильтрация по художественным направлениям.
   - Полная двуязычность **RU / EN** и два живых мира оформления (*Бархатный Индиго* и *Рассвет Таррелла*).

3. **Мастерская дня (Создание нового дня):**
   - Свободный текст + голосовой ввод через Web Speech API (`SpeechRecognition`) + опциональные дата, погода и локация (Open-Meteo + Nominatim).
   - Загрузка 1–6 реальных фотографий с автоматическим извлечением 4 доминирующих цветов, яркости и контраста на **HTML5 Canvas**.
   - Музыка:
     - **Живой автоподбор из интернета** через **iTunes Search API** по настроению текста и теплоте/цветам фото (или через Gemini 2.5 Flash при наличии ключа) + ручной поиск треков с официальным 30-секундным аудио-превью и обложкой.
     - **Загрузка своего аудиофайла** (MP3/WAV/OGG) с реальным анализом RMS-энергии и пикового BPM через **Web Audio API**.

4. **Папка дня и Объяснимая логика:**
   - Автоматическое название папки (3–7 слов) по смыслу записи.
   - Озвучка текста через **Web Speech API** (`SpeechSynthesis`) с подбором темпа и высоты голоса под атмосферу дня и плавным приглушением музыки (*ducking*).
   - Прозрачный блок **«Почему день выглядит так»** с разбором влияния текста, фото и музыки.
   - Экспорт готовой страницы-открытки в **PNG**, запись **7-секундного видео WebM со звуком** (`captureStream` + `MediaRecorder`), а также экспорт/импорт папок `.atmos.json`.

## Единая визуальная система

- **Постоянные элементы:** вертикальный формат **4:5**, внешняя рамка-паспарту, моноширинный индекс `ДЕНЬ // XX`, 4 Pantone-чипа палитры дня, дата и погода, заголовок папки (*Cormorant Garamond*), строка музыкального пульса и рукописная подпись (*Caveat*).
- **Переменные элементы:** палитра из фото, плотность «воздуха», плёночное зерно, ритм смены кадров, погодные частицы и 4 художественных приёма:
  1. **Импрессионизм (Клод Моне)** — для тёплых, спокойных и ностальгических дней.
  2. **Конструктивизм (Василий Кандинский)** — для напряжённых, энергичных и ритмичных дней.
  3. **Японский минимализм (Ваби-саби)** — для тихих, медленных и созерцательных дней.
  4. **Аналоговая киноплёнка 35mm / Коллаж** — для живых городских прогулок, закатов и уличных хроник.
